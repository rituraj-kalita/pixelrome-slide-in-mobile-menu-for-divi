== Description ==

PIXELROME – Slide-In Mobile Menu for Divi enhances the default Divi mobile navigation with a modern off-canvas slide-in panel.

Instead of the standard dropdown mobile menu, this plugin provides a smooth right-to-left animated slide panel for improved usability and cleaner mobile navigation.

It integrates seamlessly with the Divi theme and allows you to customize menu styling directly from the WordPress admin panel.

= Features =

- Smooth right-to-left slide-in animation
- Fully responsive mobile behavior
- Customizable hamburger icon color
- Customizable menu background color
- Typography controls (font size, weight, color)
- Adjustable inner padding and item spacing
- Adjustable menu width
- Optional close-on-link-click
- Dropdown submenu support with smooth expand/collapse
- Accessible (ARIA support for menu and toggles)

= Requirements =

- Divi theme must be active
- WordPress 5.8+
- PHP 7.4+

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the “Plugins” screen in WordPress
3. Make sure Divi theme is active
4. Go to **Slide-In Menu** in the WordPress admin
5. Select your navigation menu and configure settings

== Frequently Asked Questions ==

= Does this work with themes other than Divi? =

No. This plugin is designed specifically for the Divi theme.

= Does this replace the default Divi mobile menu? =

Yes. It hides the default Divi mobile hamburger and replaces it with a slide-in panel.

= Can I customize the animation direction? =

Right-to-left animation is included in Lite. Additional directions will be available in Pro.
